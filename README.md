\# Hyat Store Dashboard Data Analysis



\## Project Overview



This project focuses on analyzing the sales data of Hyat Store across different online shopping platforms, including Amazon, Flipkart, and Ajio. The objective was to understand sales performance, customer purchasing patterns, and business trends through data analysis and an interactive dashboard developed in Microsoft Excel.



\## Data Cleaning and Preparation



Before creating the dashboard, I worked on preparing the raw dataset to make it suitable for analysis. The gender column contained inconsistent entries such as Men, Women, and MWI. I standardized these values into two categories: Men and Women.



The age column contained numerical values, which I grouped into three categories: Teenager, Adult, and Senior. This classification made it easier to analyze purchasing patterns across different age groups.



I also identified missing values in the dataset and handled them appropriately to maintain data consistency and improve the reliability of the analysis. Further data preparation involved standardizing values and organizing the dataset for effective analysis.



\## Dashboard and Analysis



After cleaning and preparing the data, I created an interactive dashboard in Microsoft Excel to present the findings in a clear and understandable manner. The dashboard provides insights into sales performance, customer demographics, and purchasing patterns across different platforms.



Interactive elements such as slicers and charts allow users to explore the data from different perspectives and understand the underlying trends.
